# King Configs Secure Ticket Bot 🤖

یک ربات تلگرامی کاملاً حرفه‌ای، ماژولار و پیشرفته بر پایه کتابخانه `python-telegram-bot` نسخه 21+ و دیتابیس SQLite، بهینه‌سازی شده برای استقرار روی پلتفرم **Railway**.

## قابلیت‌ها
- سیستم ثبت تیکت امن با پشتیبانی از متن، عکس، ویدیو، ویس و فایل (تا ۳ پیام در هر تیکت)
- قابلیت ویرایش تک‌تک بخش‌های تیکت قبل از ارسال نهایی
- پنل مدیریت پیشرفته مختص ادمین (`ADMIN_ID`) شامل آمار، مدیریت کاربران، مشاهده تیکت‌های باز و بسته و ارسال پیام همگانی
- پاسخ‌دهی مستقیم ادمین به تیکت‌ها و بستن آن‌ها
- محدودیت ۳ تیکت باز برای هر کاربر
- معماری کاملاً ناهمگام (Async/Await) بدون خطا و اخطار

## راه‌اندازی و دیپلوی روی Railway
1. پروژه را به گیت‌هاب متصل کنید.
2. متغیرهای محیطی زیر را در تنظیمات متغیرهای Railway وارد کنید:
   - `TOKEN`: توکن ربات تلگرام شما از `@BotFather`
   - `ADMIN_ID`: شناسه عددی تلگرام ادمین ربات
3. پلتفرم Railway به طور خودکار فایل `requirements.txt` را خوانده و ربات را با دستور `python main.py` اجرا می‌کند.
